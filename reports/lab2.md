## 实现的功能

- 重写了 `sys_get_time` 和 `sys_trace`。其实我一开始并不知道为什么这些功能失效了，问了 AI 才知道是内核无法直接写指针，需要地址转换。其中 `sys_trace` 的实现也没有照抄前一章，得益于堆分配器，可以使用 `BTreeMap`，简化了逻辑。
- 实现了 `mmap` 和 `munmap`。遇到的主要问题是调用哪些已有 API 来实现功能。以 `mmap` 为例，一开始我是直接调用应用 `frame_alloc` 以及页表的 `map` 方法，但一个测试点始终无法通过，使我发现它并无法保存 `FrameTracker` 而只能保存 PPN，导致刚申请的页帧被释放。于是才找到了 `map_one` 方法，能够实现 `FrameTracker` 的保存；向上追溯公开 API 到任务地址空间的 `insert_framed_area` 方法，作为最终方案。
